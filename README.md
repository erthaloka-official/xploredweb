# xplorED — Connecting Learning to the Real World

> The digital front door to a connected real-world learning ecosystem.  
> **Explore | Experience | Evolve** through People, Places, Programs & Partners.

---

## 🌍 Overview

**xplorED** bridges theoretical academics with hands-on, practical, and experiential real-world learning. From hardware-in-the-loop autonomous testing bays in Stuttgart to regenerative soil microbiomics in Karnataka and biomimicry architectures in Paris, xplorED connects learners directly with authentic environments and verified master practitioners.

---

## ✨ Features

- **Core Discovery Pillars**: Filter and explore across **People**, **Places**, **Programs**, and **Possibilities**.
- **Interactive Continuous Learning Loop**: Discover -> Experience -> Reflect -> Evolve workflow visualization.
- **Institutional Pilot Builder**: Multi-step configuration flow for university deans and K-12 directors to assemble bespoke experiential sprints.
- **Deep-Dive Experience Modals**: High-fidelity itinerary breakdowns, measurable learning outcomes, and prerequisites.
- **Global Footprint**: Interactive world explorer connecting hubs across India, Germany, Japan, and France.
- **Buttery Smooth Scroll Reveals**: 60fps spring-eased micro-interactions & intersection observers without heavy particle bloat.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/erthaloka-official/xploredweb.git

# Navigate into project directory
cd xploredweb

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
